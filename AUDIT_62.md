## Правильный порядок подстановок

На курсе сначала действует левая подстановка: (στ)(i)=τ(σ(i)). Это не правило для умножения числовых матриц. Предыдущий визуальный PDF использовал другой порядок, поэтому он оставлен только как архивное визуальное пособие и явно помечен.

Для официальной №178 при A=(7,3,2,1,6,5,4), B=(3,1,2,7,4,5,6), C=(5,1,3,6,4,7,2) правильная X при соглашении слева направо имеет образы (7,1,2,3,4,5,6). Проверка B(X(A(i)))=C(i) проведена для всех i=1..7.
