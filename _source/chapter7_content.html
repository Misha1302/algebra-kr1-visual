01 / LU-разложение

Метод Гаусса, только мы сохраняем его шаги

Вспомни: методом Гаусса мы вычитали строки, чтобы получить нули под диагональю. Полученную матрицу называют верхнетреугольной, или U. Но есть ещё один вопрос: какую строку и сколько раз вычитали? Эти коэффициенты можно записать отдельно в матрицу L.

LНижняя треугольная

Выше диагонали стоят нули. В этой задаче на диагонали L — единицы, под диагональю — коэффициенты исключения.

UВерхняя треугольная

Когда LU без перестановки строк не получится?

Например, A=[[0,1],[1,1]]. Если L имеет единицы на диагонали, а U — ноль под диагональю, то из верхней левой клетки следует U₁₁ = 0. Тогда нижняя левая клетка произведения LU тоже будет 0, но в исходной матрице там 1. Противоречие. Нужно сначала поменять строки: тогда записывают PA = LU, где P выполняет эту перестановку. Нулевой ведущий элемент — сигнал проверить перестановку, а не делить на ноль.

02 / Скелетное разложение

Оставляем независимые столбцы, остальные восстанавливаем

У матрицы есть три столбца. Но если третий получается сложением первых двух, то для его восстановления достаточно знать два первых столбца и правило сложения. Это и есть скелетное разложение: A = B·C.

Что здесь ищемКакие столбцы не выражаются друг через друга?И как получить оставшиеся?

  2. Собираем из них B. Просто переписываем из исходной A первый и второй столбцы. Получаем B = [[1,2],[2,5]]. Здесь ничего не вычитаем и не транспонируем.
  3. Ищем коэффициенты для третьего столбца. Пусть α·(1,2) + β·(2,5) = (3,7). По строкам получаем α + 2β = 3 и 2α + 5β = 7. Вычтем из второго уравнения удвоенное первое: β = 1. Тогда α = 1.
  4. Составляем C. Для восстановления первого столбца возьмём 1·первый + 0·второй: (1,0). Для второго — (0,1). Для третьего — найденные коэффициенты (1,1). Эти три пары записываем столбцами C.

Самостоятельная проверка

Как восстановить новый столбец?

Первые два столбца: b₁=(1,2)ᵀ и b₂=(1,3)ᵀ. Третий столбец равен (5,13)ᵀ. Найди α и β в равенстве αb₁ + βb₂ = (5,13)ᵀ.

Показать вычисление

Составляем систему: α + β = 5, 2α + 3β = 13. Вычтем удвоенное первое из второго: β = 3. Значит α = 2. Проверка: 2·(1,2) + 3·(1,3) = (5,13).

03 / Рекуррентные соотношения

Большой определитель из двух меньших

Здесь мы уже не ищем произведение матриц. Нужен один результат — определитель. Для особого вида матриц его удобно считать, не раскрывая каждый раз десятки слагаемых.

Трёхдиагональная матрица: ненулевые числа могут быть только на главной диагонали и на двух соседних диагоналях. У нашего примера на главной стоит 5, над ней 2, под ней 3:

Что означает Dₙ?D₂ — определитель матрицы 2×2 этого вида.D₃ — матрицы 3×3; D₄ — матрицы 4×4 и так далее.
  1. Начинаем с D₁. Матрица из одного числа 5 имеет определитель D₁=5. Дополнительно принимаем D₀=1 — соглашение, чтобы формула работала уже для D₂.
  2. Находим D₂ обычным способом. Для [[5,2],[3,5]] определитель равен 5·5 − 2·3 = 19.
  3. Раскладываем D₃ по первой строке. Выбираем 5 и 2; вклад 0 равен нулю. Для 5 остаётся определитель [[5,2],[3,5]]=19. Для 2 знак минус, а оставшийся определитель [[3,2],[0,5]]=15. Получаем D₃ = 5·19 − 2·15 = 65.
  4. Замечаем повторение. 15 = 3·5 = 3D₁. Значит D₃=5D₂−2·3D₁. В матрице следующего порядка точно так же появятся D₃ и D₂.
Откуда знак «минус» и множитель bc

В первой строке ненулевые элементы только a и b. Если раскрыть определитель по первой строке, получим:

Вклад a+a · Dₙ₋₁Удалили первую строку и первый столбец — осталась такая же матрица на порядок меньше.
Вклад b−b · c · Dₙ₋₂У позиции (1,2) знак минус. После удаления строки и столбца в первом столбце остатка единственный ненулевой элемент c.

Итак, Dₙ = aDₙ₋₁ − bcDₙ₋₂. Для a=5, b=2, c=3 это Dₙ = 5Dₙ₋₁ − 6Dₙ₋₂. Формула относится именно к такому трёхдиагональному виду, не ко всем матрицам.
