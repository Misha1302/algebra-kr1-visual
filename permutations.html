Подстановки: сначала левая, потом правая.

Два порядка перемножения существуют в математической литературе. Здесь везде используется договорённость вашего курса: произведение σ·τ означает сначала применить σ, затем τ. Ни одна задача не должна незаметно переключаться на другой порядок.

01 · Базовые определения

В каком смысле числа «переставляются»?

Перестановка — упорядоченный список из чисел 1,…,n без повторений, например (3,1,2). Подстановка σ — взаимно однозначное отображение множества {1,…,n} в себя, то есть каждому исходному номеру она ставит в соответствие ровно один новый номер, причём все результаты различны.

Запись в две строки

σ = ( 1 2 3 )
　　 ( 2 3 1 )

Верхняя строка показывает исходные номера, нижняя — их образы: σ(1)=2, σ(2)=3, σ(3)=1. Это же отображение можно записать циклом (1 2 3): 1 переходит в 2, 2 в 3, 3 в 1.

Sₙ — множество всех подстановок n элементов, их всего n! (факториал: 3!=3·2·1=6). Подстановку, которая ничего не меняет, обозначают e.

Цикл (1 2 3)

Стрелки по кругу: 1→2→3→1. Такой цикл не означает обычное число 123 и не является произведением трёх чисел.

Непересекающиеся циклы

Например, (1 3)(2 4). Они действуют на разных элементах, поэтому при композиции не мешают друг другу и их порядок можно поменять.

02 · Главное соглашение курса

Как перемножать подстановки?

Запись στ — не одновременное выполнение двух замен. Нужно пройти два последовательных шага для каждого элемента. На вашем курсе первой всегда действует левая σ, потом правая τ. Формально:

(στ)(i) = τ(σ(i))
Некоммутативность: если σ=(1 2), τ=(2 3), то по нашему соглашению σ·τ=(1 3 2), а τ·σ=(1 2 3). Эти подстановки различны: порядок важен.

Проследи путь одного элемента

Первая подстановка меняет промежуточный номер, вторая применяется к результату. Выбирай исходное число и меняй порядок.

Путь элемента

В примере σ=(1 2), τ=(2 3). На каждой стрелке можно проверить образ числа по двухстрочной записи подстановки.
Не смешивай с соглашением из других книг. При правосторонней композиции то же произведение символов означало бы другой результат. Поэтому запись (στ)(i)=τ(σ(i)) нужно писать перед первой задачей, если есть риск неоднозначности.
03 · Что такое знак подстановки?

Инверсии: в каких местах порядок сломан

Инверсия — пара позиций i<j, в которой левее стоит число больше правого: σ(i)>σ(j). Число инверсий определяет чётность подстановки: если их чётное количество, знак +1, если нечётное — −1.

sgn(σ) = (−1)^(количество инверсий)
Пример: в перестановке (3,1,4,2) видны три инверсии: 3>1, 3>2, 4>2. Значит знак −1. Числа нужно читать по очереди слева направо, проверяя каждое со всеми числами справа.

Сколько инверсий ты видишь?

Нажми на перестановку. Пары инверсий будут перечислены явно.

Подсчёт инверсий

Каждый обмен двух элементов меняет чётность, а значит и знак. Для цикла длины k знак равен (−1)^(k−1). Знаки нужны, в частности, для каждого слагаемого определителя в формуле Лейбница.

04 · Степени и корни

Почему циклы помогают считать большие степени?

Степень σᵏ — применение σ k раз подряд. У цикла длины m после каждых m шагов все элементы возвращаются на место. Например, (1 2 3)³=e, а (1 2 3)²=(1 3 2). Для непересекающихся циклов степени считаются независимо.

Официальная №177: подстановка S содержит два независимых 5-цикла, значит S⁵=e. Поскольку 150 кратно пяти, S¹⁵⁰=e. Чтобы ответ зачли, нужно показать разложение на циклы. Полное решение ↗

Квадратные корни из подстановки

В задаче σ²=(1 2 3)(4 5 6) нужно найти все подстановки σ. Нельзя просто взять по корню из каждого цикла: две тройки можно объединить в один цикл длины 6, квадрат которого даст две тройки.

Почему ответов ровно восемь?

На {1,…,6} один корень сохраняет две тройки раздельно: (1 3 2)(4 6 5). Три других корня соединяют их в один 6-цикл; выбор элемента после 1 во второй тройке даёт ровно три варианта.

(1 4 2 5 3 6)
(1 5 2 6 3 4)
(1 6 2 4 3 5)

Элементы 7 и 8 в правой части неподвижны. Корень на {7,8} может либо тоже ничего не менять, либо быть транспозицией (7 8), квадрат которой равен e. Значит 4 × 2 = 8 корней. Подробный вывод T04 ↗

05 · Разбор с правильным порядком

Официальная №178: AXB = C

Здесь A, B, C и X — подстановки, а не числовые матрицы, хотя они записаны в две строки. Операция AXB — композиция подстановок. Равенство в группе даёт X=A⁻¹CB⁻¹, но по нашему соглашению для вычисления X(i) нужно применять A⁻¹, затем C, затем B⁻¹.

Заданные отображения:
A: [7,3,2,1,6,5,4]
B: [3,1,2,7,4,5,6]
C: [5,1,3,6,4,7,2].
Каждый список задаёт образы 1,…,7. Например, A(1)=7.

Посчитай X(i) без угадывания

Выбери i: показано, куда попадает элемент после каждой подстановки, и отдельная проверка, что (AXB)(i)=C(i).

Применяем A⁻¹ → C → B⁻¹

Исправление предыдущей версии: ответ для соглашения слева направо — нижняя строка X равна (7,1,2,3,4,5,6). В предыдущем пособии был использован другой порядок, и его числовой ответ для этой задачи не подходит. Проверку проводим на всех семи значениях, а не только на одном.
