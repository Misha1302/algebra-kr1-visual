Определитель — это число, а не ещё одна матрица.

Разбираемся с нуля: почему у квадратной матрицы есть определитель, как появляется формула ad − bc, как переходить к 3×3 и большим матрицам и почему при преобразованиях строк меняется знак.

01 · Сначала определение

Что такое определитель?

Квадратная матрица — таблица, у которой число строк равно числу столбцов: 2×2, 3×3, n×n. Определитель матрицы A, обозначаемый det A или |A|, — специальное число, получаемое по правилам из элементов квадратной матрицы. Для прямоугольной матрицы определитель в обычном смысле не определён.

Для чего он нужен?

Если det A = 0, квадратная матрица не имеет обратной. Если det A ≠ 0 — имеет. В двумерной геометрии |det A| показывает, во сколько раз линейное преобразование меняет площади.

Почему знак важен?

Положительный и отрицательный определители отражают ориентацию преобразования. Перестановка двух строк меняет знак, но не модуль определителя.

Как вычисляется det 2×2?

У матрицы [[a,b],[c,d]] две диагонали. Сначала перемножь левый верхний и правый нижний элементы (ad). Затем перемножь правый верхний и левый нижний (bc). Вычти второй результат из первого.

det [[a,b],[c,d]] = a·d − b·c
Пример: det [[2,1],[3,4]] = 2·4 − 1·3 = 5. Мы получили одно число, а не таблицу.

Попробуй изменить элементы

При изменении любого числа результат пересчитывается. Синим обозначена главная диагональ, оранжевым — побочная.

02 · Прежде чем применять большую формулу

От 2×2 к определителю 3×3

Для матрицы 3×3 уже нельзя просто перемножить две диагонали. Самый надёжный способ — разложение по строке или столбцу (формула Лапласа). Чтобы понять его, нужно два новых определения.

Минор элемента Mᵢⱼ

Выбираем элемент с адресом (i,j), вычёркиваем его строку i и столбец j. Остаток — квадратная матрица на один порядок меньше. Её определитель и есть минор Mᵢⱼ. Для 3×3 остаётся 2×2, которую уже умеем считать.

Алгебраическое дополнение Cᵢⱼ

Берём минор и ставим перед ним нужный знак: Cᵢⱼ = (−1)^(i+j) · Mᵢⱼ. Знаки по позициям 3×3 образуют шахматку: (+ − +) / (− + −) / (+ − +).

Разложение по строке

Выбери, например, первую строку. Каждый её элемент умножь на своё алгебраическое дополнение, затем сложи полученные три числа. Можно выбрать любую строку или столбец: результат будет одинаков.

Нажимай на элементы строки или столбца

Матрица A зафиксирована, поэтому весь способ можно проследить вручную. Синим выделяется выбранная строка, оранжевым — столбец, зачёркнутым — исключённые позиции.

03 · Строгое общее определение D07

Почему в определителе участвуют подстановки?

Для матрицы порядка n нам нужно выбирать по одному числу из каждой строки и каждого столбца. Удобно сначала выбрать в первой строке один столбец, во второй — другой, и так далее. Такое правило выбора столбцов задаёт подстановка σ: строке i сопоставляем столбец σ(i).

Пример: σ = (2,3,1) означает: из строки 1 берём столбец 2, из строки 2 — столбец 3, из строки 3 — столбец 1. Получится произведение a₁₂·a₂₃·a₃₁. Оно входит в определитель со знаком +, потому что в (2,3,1) две инверсии.
det A = Σ[по всем σ ∈ Sₙ] sgn(σ) · a₁,σ(1) · … · aₙ,σ(n)

Инверсия — пара позиций i<j, в которых выбранные номера столбцов идут в обратном порядке: σ(i)>σ(j). Если инверсий чётное число, знак +; если нечётное, знак −. Для матрицы 3×3 существует 3! = 6 подстановок, то есть шесть слагаемых.

Все шесть слагаемых для одной 3×3

Выбери подстановку: зелёные клетки показывают, какие три числа попали в её произведение. Итоговая сумма всех шести слагаемых равна 22.

Член формулы Лейбница

Порядок композиции подстановок на вашем курсе — слева направо. При вычислении одного знака инверсии определяются последовательностью значений σ(1),…,σ(n), так что эта формула не зависит от того, как принято записывать произведение двух подстановок. Изучить подстановки подробно ↗

04 · Что разрешено при вычислении

Свойства определителя

Именно свойства позволяют быстро приводить матрицы к треугольному виду и не раскрывать огромную сумму из n! членов.

Поменять две строки местами

Знак определителя меняется: det A′ = −det A. Такое же правило для столбцов.

Умножить одну строку на k

Определитель умножится на k (при k=0 станет 0).

К строке прибавить k·другую строку

Определитель не меняется — главный инструмент метода Гаусса.

Одинаковые строки / нулевая строка

det A = 0: нет независимости, поэтому обратной матрицы нет.

Треугольная матрица

det A — произведение диагональных элементов. Нули под/над диагональю упрощают задачу.

Транспонирование и произведение

det(Aᵀ)=det A; det(AB)=det A·det B (если A и B квадратные одного порядка).

Проверь свойства на числах

Начинаем с матрицы A = [[2,1],[3,4]], det A = 5. Выбери преобразование первой/второй строки и посмотри, что произошло.

Не путай: для матриц вообще неверно det(A+B)=det A+det B. И формула «три диагонали вправо минус три влево» (правило Саррюса) работает только для 3×3, а не для порядка 4 или n.
05 · Определители произвольного порядка

Как считать det n×n без n! слагаемых?

1. Приведение к треугольному виду

Используй элементарные преобразования строк. Если только прибавляешь к строке кратную другой, det не меняется. При перестановке строк учитывай знак; при умножении строки — множитель. После получения треугольной матрицы перемножь числа на диагонали.

2. Рекурсия для трёхдиагональной матрицы

Трёхдиагональная матрица содержит ненулевые элементы лишь на главной диагонали и двух соседних. Если главная диагональ равна a, над ней b, под ней c, то определители Dₙ соседних порядков связаны:

D₀ = 1, D₁ = a, Dₙ = a·Dₙ₋₁ − (b·c)·Dₙ₋₂

Почему? Разложи определитель по первой строке. В ней лишь два ненулевых элемента: a и b. Их миноры выражаются через матрицы порядка n−1 и n−2. Упрощение даёт указанную рекурсию. Полный разбор официальной T08 ↗

3. Особые формулы

Постоянная диагональ 3, вне неё 2

Для n×n матрицы A = I + 2J, где J — матрица из единиц, det A = 2n + 1. Используй собственные значения J или операции со строками. №283 ↗

Вандермонд

У матрицы со строками (1, xᵢ, xᵢ²,…) определитель равен произведению разностей ∏_{i<j}(xⱼ−xᵢ). Для x=(1,2,4): (2−1)(4−1)(4−2)=6. №348 ↗

Рекурсия — метод для специально устроенных матриц. Для произвольной матрицы порядок n вычисляют методом Гаусса или разложением Лапласа, а не применяют формулу трёхдиагонального случая.
