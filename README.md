# Алгебра наглядно · КР №1 (2026)

Полноценный статический сайт-учебник по первой контрольной по линейной алгебре: 62 официальных пункта, отдельные интерактивные уроки и проверяемая конвенция подстановок слева направо.

**Сайт:** https://misha1302.github.io/algebra-kr1-visual/

## Что есть на сайте

- [Определители](determinants.html): смысл, 2×2, 3×3, формула Лейбница, свойства, разложение Лапласа, трёхдиагональные определители и рекурсии — с интерактивными расчётами.
- [Подстановки](permutations.html): композиция **слева направо**, циклы, инверсии, степени, корни и исправленное решение №178 — с проверкой семи значений.
- [Полный онлайн-учебник](textbook.html): все темы, 26 определений, 11 доказательств, 12 основных и 13 дополнительных задач. [PDF с исправленным порядком подстановок](assets/Algebra_KR1_2026_LEFT_TO_RIGHT_FULL.pdf) — печатная версия того же текста.
- [Список 62 пунктов](syllabus.html): каждый пункт связан с конкретным разделом.
- [Доказательства](proofs.html): 11 отдельных подробных доказательств.
- [Задачи](problems.html): 25 официальных заданий с решениями, скрытыми до нажатия.
- [Словарь 26 определений](definitions.html) и [интерактивная матричная лаборатория](lab.html) — первый вход для новичка.

**Соглашение курса:** произведение подстановок στ действует слева направо, то есть (στ)(i)=τ(σ(i)). Это не порядок умножения матриц. Старый визуальный PDF содержит другое соглашение; для задач на произведения подстановок используй актуальную онлайн-версию. №178 в онлайн-версии пересчитана: X=[7,1,2,3,4,5,6].

## С чего начать

1. Начните со [словаря 26 определений](https://misha1302.github.io/algebra-kr1-visual/definitions.html) — каждое понятие дано простыми словами, строго и на конкретном примере.
2. Откройте [лабораторию матриц](https://misha1302.github.io/algebra-kr1-visual/lab.html) и нажимайте на клетки результата умножения.
3. Изучайте [наглядный PDF-учебник](assets/Algebra_KR1_2026_VISUAL.pdf) (53 страницы).
4. Решите [мини-КР без подсказок](assets/KR1_Practice_No_Answers.pdf), затем проверьте [ответы](assets/KR1_Answer_Key.pdf).

## Локальный запуск

Сайт полностью статический. Можно просто открыть `index.html` в браузере или запустить:

```bash
python3 -m http.server 8080
```

и открыть http://localhost:8080/.

## Обновление GitHub Pages

GitHub Pages публикует каталог `/` ветки `main`. Для новой версии достаточно обновить файлы и отправить commit в `main`.

## Важные замечания

Интерактивная лаборатория использует фиксированные учебные примеры, а не произвольный матричный калькулятор. Полные определения и доказательства находятся в PDF. Материал предназначен для самостоятельной подготовки, но числовые примеры не заменяют общие доказательства.

Материалы размещены для ознакомления; отдельная лицензия на распространение/производные работы не предоставлена.
