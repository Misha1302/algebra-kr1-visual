**Открыть сайт:** https://misha1302.github.io/algebra-kr1-visual/

Самостоятельный учебный сайт к первой контрольной по алгебре. Принцип: **конкретное действие → объяснение → строгая формулировка → проверка**. Предназначен для читателя, который впервые сталкивается с матрицами, определителями, рангом и системами уравнений.

## Где именно учиться

**[Начать с учебника](definitions.html)** — основной путь. Вместо 26 кратких изолированных карточек — семь связанных глав с полноформатными объяснениями, пошаговыми числовыми примерами, интерактивными матрицами и проверкой понимания. Все официальные определения D01–D26 встроены по смыслу в главы и доступны по якорям, например [D12 — союзная матрица](definitions.html#D12).

Главы: матрицы и транспонирование → Гаусс → подстановки и определители → Крамер, adj и обратная матрица → ранг и независимость → системы и Кронекер — Капелли → LU, скелетное разложение и рекуррентные определители.

## Порядок композиции подстановок

В соответствии с соглашением курса подстановки выполняются **слева направо**:

~~~text
(στ)(i) = τ(σ(i))
~~~

Это правило относится к подстановкам и не меняет стандартные определения произведения матриц. В задаче №178 при этом получается нижняя строка **(7,1,2,3,4,5,6)**; она проверена подстановкой для всех семи аргументов.

Старый файл assets/Algebra_KR1_2026_VISUAL.pdf сохранён лишь как исторический иллюстрированный материал: его прежнее соглашение для подстановок противоположно принятому на курсе. Для задач на композиции используй актуальное онлайн-издание или новую печатную PDF-версию.

## Как устроен проект

~~~text
definitions.html             Основной последовательный учебник, D01–D26

_source/                     Исходный Markdown и сборщики
~~~

Сайт статический: достаточно открыть index.html или запустить команду python3 -m http.server 8080. Никакой серверной БД или внешней библиотеки для работы тренажёров не требуется. Прогресс ответов в семи мини-проверках сохраняется локально в браузере и никуда не отправляется.

## Проверка изменений

~~~bash
node --check assets/learn.js
python3 tests/math_invariants.py
python3 tests/learning_journey.py
python3 tests/site_smoke.py
python3 tests/full_site_smoke.py
~~~

Для браузерных тестов нужны Python Playwright и установленный Chromium, а для математического теста — SymPy. Прямые ссылки на D01–D26 и покрытие 62 пунктов проверяются автоматически.

**Ограничение:** 62/62 официальных пунктов имеют полные текстовые разборы и прямые ссылки, но отдельная интерактивная модель создана не для каждого из 62 пунктов. Это не официальный сайт преподавателя: точные номера и темы взяты из исходных материалов, учебные объяснения и решения подготовлены отдельно.
