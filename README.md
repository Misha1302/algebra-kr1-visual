# Линейная алгебра наглядно · КР №1 (2026)

**Открыть сайт:** https://misha1302.github.io/algebra-kr1-visual/

Самостоятельный учебный сайт к первой контрольной по алгебре. Принцип: **конкретное действие → объяснение → строгая формулировка → проверка**. Предназначен для читателя, который впервые сталкивается с матрицами, определителями, рангом и системами уравнений.

## Где именно учиться

**[Начать с учебника](definitions.html)** — основной путь. Вместо 26 кратких изолированных карточек — семь связанных глав с полноформатными объяснениями, пошаговыми числовыми примерами, интерактивными матрицами и проверкой понимания. Все официальные определения D01–D26 встроены по смыслу в главы и доступны по якорям, например [D12 — союзная матрица](definitions.html#D12).

Главы: матрицы и транспонирование → Гаусс → подстановки и определители → Крамер, adj и обратная матрица → ранг и независимость → системы и Кронекер — Капелли → LU, скелетное разложение и рекуррентные определители.

- [Подстановки](permutations.html) — композиция **слева направо**, циклы, инверсии, степени, корни и исправленное решение №178.

- [11 доказательств](proofs.html) — полные строгие тексты плюс предпосылки, 22 проверки логических переходов и письменная самопроверка.

## Автономная практика и независимое QA

- [24 самостоятельных задания](practice.html): восемь направлений по три новых варианта. Числовые шаги проверяются точно, есть объяснения ошибок и необязательные подсказки. Это не свободная генерация заданий на любые данные, а проверенные исходные варианты.
- [Пробная диагностика](exam.html): восемь заданий с ответами, скрытыми до завершения попытки.
- [25 официальных задач](problems.html): исходное условие, отдельные подсказки и полный разбор, черновик, один новый вариант с ручной самопроверкой для каждой задачи.
- [11 доказательств](proofs.html): два вопроса о логике, необходимые предпосылки, вспомогательный пример, письменная попытка и полный эталон для каждого.
- [Матрица 62 пунктов](docs/remediation/62_COVERAGE_POST_REMEDIATION.csv): конкретное покрытие и открытые педагогические ограничения.
- [Источник и правовой статус](docs/remediation/CONTENT_PROVENANCE.md): происхождение официальных условий и внешних материалов, ограничения на распространение.

Счётчики проверенных шагов и мини-тестов не означают, что студент освоил все определения и доказательства. Пилотного исследования с реальными новичками не проводилось.

### Разработка и воспроизводимые проверки

Для генерации нужны Python, Pandoc 3.6.4 и зависимости из requirements-test.txt. Генераторы: _source/build_textbook.py, _source/build_catalog.py, _source/build_transfer.py, _source/build_coverage.py. Выполняйте их именно в таком порядке. Основной CI сверяет результат генерации с закоммиченными файлами, запускает четыре исторических тестовых набора и четыре новых. После публикации отдельный workflow pages-postdeploy-smoke.yml проверяет 11 HTML, 4 PDF, CSS/JS, фактический HTTP, работу интерфейсов и точные SHA опубликованных файлов.

## Порядок композиции подстановок

В соответствии с соглашением курса подстановки выполняются **слева направо**:

~~~text
(στ)(i) = τ(σ(i))
~~~

Это правило относится к подстановкам и не меняет стандартные определения произведения матриц. В задаче №178 при этом получается нижняя строка **(7,1,2,3,4,5,6)**; она проверена подстановкой для всех семи аргументов.

Старый файл assets/Algebra_KR1_2026_VISUAL.pdf сохранён лишь как исторический иллюстрированный материал: его прежнее соглашение для подстановок противоположно принятому на курсе. Для задач на композиции используй актуальное онлайн-издание или новую печатную PDF-версию.

## Как устроен проект

~~~text
definitions.html             Основной последовательный учебник, D01–D26
assets/learn.css             Типографика, матрицы, выделения, адаптивность
assets/learn.js              Интерактивные примеры и контроль понимания
determinants.html            Подробный урок по определителям
permutations.html            Подробный урок по подстановкам
lab.html                     Восемь дополнительных тренажёров
textbook.html                Полный текст для повторения/доказательств
proofs.html                  11 доказательств
problems.html                25 задач с раскрываемыми решениями
syllabus.html                Карта официальной программы: 62 ссылки
_source/                     Исходный Markdown и сборщики
tests/                       Математические и браузерные проверки
~~~

Сайт статический: достаточно открыть index.html или запустить команду python3 -m http.server 8080. Никакой серверной БД или внешней библиотеки для работы тренажёров не требуется. Отдельно сохраняются результаты семи мини-проверок и восьми типов самостоятельных упражнений. Это не измерение готовности к КР. Данные хранятся локально в браузере и не отправляются на сервер.

## Проверка изменений

~~~bash
node --check assets/learn.js
python3 tests/math_invariants.py
python3 tests/learning_journey.py
python3 tests/site_smoke.py
python3 tests/full_site_smoke.py
~~~

Для браузерных тестов нужны Python Playwright и установленный Chromium, а для математического теста — SymPy. Прямые ссылки на D01–D26 и покрытие 62 пунктов проверяются автоматически.

**Ограничение:** 62/62 официальных пунктов имеют полные текстовые разборы и прямые ссылки, но отдельная интерактивная модель создана не для каждого из 62 пунктов. Это не официальный сайт преподавателя: точные номера и темы взяты из исходных материалов, учебные объяснения и решения подготовлены отдельно.
