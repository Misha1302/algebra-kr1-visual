# Алгебра наглядно · КР №1 (2026)

Статический сайт с визуальным пособием и интерактивной лабораторией по линейной алгебре.

**Сайт:** https://misha1302.github.io/algebra-kr1-visual/

## С чего начать

1. Начните со [словаря 26 определений](https://misha1302.github.io/algebra-kr1-visual/definitions.html) — каждое понятие дано простыми словами, строго и на конкретном примере.
2. Откройте [лабораторию матриц](https://misha1302.github.io/algebra-kr1-visual/lab.html) и нажимайте на клетки результата умножения.
3. Изучайте [наглядный PDF-учебник](assets/Algebra_KR1_2026_VISUAL.pdf) (53 страницы).
4. Решите [мини-КР без подсказок](assets/KR1_Practice_No_Answers.pdf), затем проверьте [ответы](assets/KR1_Answer_Key.pdf).

## Что внутри

- Все 26 официальных определений в поисковом словаре и пошаговые объяснения до примеров.
- 8 интерактивных разделов: умножение матриц, размеры, транспонирование, Гаусс, минор и adj, ранг с параметром, LU и скелетное разложение, самопроверка.
- PDF с 18 поясняющими рисунками и пошаговыми числовыми примерами.
- Разделы с 26 определениями, 11 доказательствами, 12 основными и 13 дополнительными задачами.
- Отдельная мини-КР и ответы.

## Локальный запуск

Сайт полностью статический. Можно просто открыть `index.html` в браузере или запустить:

```bash
python3 -m http.server 8080
```

и открыть http://localhost:8080/.

## Обновление GitHub Pages

GitHub Pages публикует каталог `/` ветки `main`. Для новой версии достаточно обновить файлы и отправить commit в `main`.

## Важные замечания

Интерактивная лаборатория использует фиксированные учебные примеры, а не произвольный матричный калькулятор. Полные определения и доказательства находятся в PDF. Материал предназначен для самостоятельной подготовки, но числовые примеры не заменяют общие доказательства.

Материалы размещены для ознакомления; отдельная лицензия на распространение/производные работы не предоставлена.
