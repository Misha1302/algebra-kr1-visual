P01. Транспонирование произведения

Утверждение. (AB)T=BTAT(AB)^T=B^TA^T.

Доказательство. Пусть AA имеет размер m×pm\times p, BB — p×np\times n. Тогда ((AB)T)ij=(AB)ji=∑k=1pajkbki((AB)^T)_{ij}=(AB)_{ji}=\sum_{k=1}^{p}a_{jk}b_{ki}. С другой стороны, (BTAT)ij=∑k=1p(BT)ik(AT)kj=∑k=1pbkiajk(B^TA^T)_{ij}=\sum_{k=1}^{p}(B^T)_{ik}(A^T)_{kj}=\sum_{k=1}^{p}b_{ki}a_{jk}. Суммы одинаковы, поэтому совпадают все элементы и размеры обеих матриц. ▫\square

План за 20 секунд: размеры →\to (AB)ijT=(AB)ji(AB)^T_{ij}=(AB)_{ji} →\to две суммы →\to совпадение.

Проверка понимания: почему (ABC)T=CTBTAT(ABC)^T=C^TB^TA^T?

P02. Определитель при транспонировании (в студенческом конспекте отсутствует)

Утверждение. Для любой квадратной AA: det⁡AT=det⁡A\det A^T=\det A.

Доказательство из определения D07.

det⁡AT=∑σ∈Snsgn⁡σ∏i=1n(AT)iσ(i)=∑σ∈Snsgn⁡σ∏i=1naσ(i),i.\det A^T=\sum_{\sigma\in S_n}\operatorname{sgn}\sigma\prod_{i=1}^{n}(A^T)_{i\sigma(i)} =\sum_{\sigma\in S_n}\operatorname{sgn}\sigma\prod_{i=1}^{n}a_{\sigma(i),i}.

Обозначим τ=σ−1\tau=\sigma^{-1}. Обоснуем равенство знаков, не предполагая мультипликативности. Инверсии σ\sigma и σ−1\sigma^{-1} попарно соответствуют друг другу: для любой пары i<ji<j, где σ(i)>σ(j)\sigma(i)>\sigma(j), обозначим u=σ(j)u=\sigma(j), v=σ(i)v=\sigma(i). Тогда u<vu<v, но σ−1(u)=j>i=σ−1(v)\sigma^{-1}(u)=j>i=\sigma^{-1}(v); получена инверсия обратной подстановки. Обратное соответствие строится тем же способом. Поэтому N(σ)=N(σ−1)N(\sigma)=N(\sigma^{-1}) и sgn⁡τ=sgn⁡σ\operatorname{sgn}\tau=\operatorname{sgn}\sigma. Замена σ↦τ\sigma\mapsto\tau биективна на SnS_n. Переименовав индекс j=σ(i)j=\sigma(i), получаем ∏iaσ(i),i=∏jaj,τ(j)\prod_i a_{\sigma(i),i}=\prod_j a_{j,\tau(j)}. Следовательно,

det⁡AT=∑τ∈Snsgn⁡τ∏j=1najτ(j)=det⁡A.▫\det A^T=\sum_{\tau\in S_n}\operatorname{sgn}\tau\prod_{j=1}^{n}a_{j\tau(j)}=\det A.\quad\square

План: формула Лейбница →\to заменить aija_{ij} на ajia_{ji} →\to σ−1\sigma^{-1} →\to sgn⁡σ−1=sgn⁡σ\operatorname{sgn}\sigma^{-1}=\operatorname{sgn}\sigma.

P03. Кососимметричность определителя по столбцам (в студенческом конспекте отсутствует)

Утверждение. При перестановке любых двух столбцов определитель умножается на −1-1.

Доказательство. Пусть π\pi — транспозиция двух номеров столбцов, то есть sgn⁡π=−1\operatorname{sgn}\pi=-1, и A′A' получена из AA перестановкой этих столбцов. По определению a′ij=ai,π(j)a'_{ij}=a_{i,\pi(j)}. Тогда

det⁡A′=∑σ∈Snsgn⁡σ∏i=1nai,π(σ(i)).\det A'=\sum_{\sigma\in S_n}\operatorname{sgn}\sigma\prod_{i=1}^{n}a_{i,\pi(\sigma(i))}.

Почему знак меняется: обозначим sk=(kk+1)s_k=(k\;k+1) — обмен соседних значений kk и k+1k+1 в результатах подстановки. Такой обмен изменяет число инверсий на 1: меняется только относительный порядок этих двух значений; для любого третьего значения оно либо меньше обоих, либо больше обоих. Любая транспозиция двух значений a<ba<b раскладывается в нечётное число 2(b−a)−12(b-a)-1 таких соседних обменов (переместить aa к bb и восстановить порядок промежуточных значений). Следовательно, композиция с транспозицией меняет чётность. В нашем соглашении (сначала левый множитель) σπ\sigma\pi означает сначала σ\sigma, затем π\pi, и sgn⁡(σπ)=−sgn⁡σ\operatorname{sgn}(\sigma\pi)=-\operatorname{sgn}\sigma.

Сделаем замену ρ=σπ\rho=\sigma\pi (сначала σ\sigma, затем π\pi). Она биективна на SnS_n, а доказанное свойство даёт sgn⁡ρ=−sgn⁡σ\operatorname{sgn}\rho=-\operatorname{sgn}\sigma. Поэтому

det⁡A′=−∑ρ∈Snsgn⁡ρ∏i=1naiρ(i)=−det⁡A.▫\det A'=-\sum_{\rho\in S_n}\operatorname{sgn}\rho\prod_{i=1}^{n}a_{i\rho(i)}=-\det A.\quad\square

План: перестановка столбцов = композиция индекса с транспозицией π\pi →\to замена индекса ρ=σπ\rho=\sigma\pi →\to знак меняется.

P04. Кососимметричность ⇔ нуль на совпадающих аргументах

Утверждение. Для функции FF от nn столбцов, линейной по каждому аргументу над ℝ\mathbb R, эквивалентны: (a) перестановка двух аргументов меняет знак FF; (b) F=0F=0, если две позиции заняты одинаковыми векторами.

Доказательство (a) ⇒\Rightarrow (b). Если два аргумента равны, то их перестановка не меняет сам набор аргументов, но по (a) меняет значение на противоположное. Значит F=−FF=-F и F=0F=0, поскольку работаем над ℝ\mathbb R.

Доказательство (b) ⇒\Rightarrow (a). Зафиксируем остальные аргументы, возьмём два вектора u,vu,v. По (b) F(…,u+v,…,u+v,…)=0F(\ldots,u+v,\ldots,u+v,\ldots)=0. Раскрыв обе позиции по линейности, получаем

0=F(…,u,…,u,…)+F(…,u,…,v,…)+F(…,v,…,u,…)+F(…,v,…,v,…).0=F(\ldots,u,\ldots,u,\ldots)+F(\ldots,u,\ldots,v,\ldots)+F(\ldots,v,\ldots,u,\ldots)+F(\ldots,v,\ldots,v,\ldots).

Первое и последнее слагаемые равны нулю по (b), поэтому F(…,u,…,v,…)=−F(…,v,…,u,…)F(\ldots,u,\ldots,v,\ldots)=-F(\ldots,v,\ldots,u,\ldots). ▫\square

План: F=−FF=-F при совпадении →\to для обратной стороны подставить u+vu+v в обе позиции →\to раскрыть 4 слагаемых.

Проверка: где мы использовали линейность по обоим аргументам?

P05. Три условия, определяющие детерминант; случай 2×2

Утверждение. Функция F(c1,…,cn)F(c_1,\ldots,c_n) совпадает с определителем, если она (1) полилинейна (линейна по каждому столбцу), (2) кососимметрична и (3) нормирована F(e1,…,en)=1F(e_1,\ldots,e_n)=1.

Доказательство для 2×22\times2 (этого требует официальный вопрос). Пусть c1=(a,c)T=ae1+ce2c_1=(a,c)^T=ae_1+ce_2, c2=(b,d)T=be1+de2c_2=(b,d)^T=be_1+de_2. По билинейности

F(c1,c2)=abF(e1,e1)+adF(e1,e2)+cbF(e2,e1)+cdF(e2,e2).F(c_1,c_2)=abF(e_1,e_1)+adF(e_1,e_2)+cbF(e_2,e_1)+cdF(e_2,e_2).

Из кососимметричности и P04 F(e1,e1)=F(e2,e2)=0F(e_1,e_1)=F(e_2,e_2)=0, а F(e2,e1)=−F(e1,e2)=−1F(e_2,e_1)=-F(e_1,e_2)=-1 и F(e1,e2)=1F(e_1,e_2)=1. Следовательно,

F(c1,c2)=ad−bc=det⁡(abcd).▫F(c_1,c_2)=ad-bc=\det\begin{pmatrix}a&b\\c&d\end{pmatrix}.\quad\square

План: три свойства →\to разложить столбцы по e1,e2e_1,e_2 →\to четыре слагаемых →\to 0,1,-1 →\to ad−bcad-bc.

P06. Определитель произведения

Утверждение. Для квадратных матриц A,BA,B одинакового порядка det⁡(AB)=det⁡Adet⁡B\det(AB)=\det A\,\det B.

Доказательство. Зафиксируем AA и рассмотрим G(b1,…,bn)=det⁡(Ab1,…,Abn)G(b_1,\ldots,b_n)=\det(Ab_1,\ldots,Ab_n) как функцию столбцов BB. Она линейна по каждому столбцу (линейны умножение на AA и определитель), кососимметрична (если поменять два столбца BB, поменяются два столбца ABAB). При подстановке стандартных базисных столбцов получаем G(e1,…,en)=det⁡AG(e_1,\ldots,e_n)=\det A.

Разложим каждый bj=∑i=1nbijeib_j=\sum_{i=1}^{n}b_{ij}e_i. По полилинейности G(B)G(B) — сумма по всем наборам индексов. Слагаемые с повторяющимися индексами равны нулю по кососимметричности. Для набора σ(1),…,σ(n)\sigma(1),\ldots,\sigma(n) без повторов имеем

G(eσ(1),…,eσ(n))=sgn⁡σdet⁡A.G(e_{\sigma(1)},\ldots,e_{\sigma(n)})=\operatorname{sgn}\sigma\,\det A.

Значит

G(B)=det⁡A∑σ∈Snsgn⁡σ∏j=1nbσ(j),j=det⁡Adet⁡B.G(B)=\det A\sum_{\sigma\in S_n}\operatorname{sgn}\sigma\prod_{j=1}^{n}b_{\sigma(j),j}=\det A\,\det B.

В последнем равенстве сумма — формула для det⁡BT\det B^T, а она равна det⁡B\det B по P02. ▫\square

План: фиксируем AA →\to G(B)=det⁡(AB)G(B)=\det(AB) линейна и кососимметрична →\to значение на EE равно det⁡A\det A →\to раскрытие по базисным столбцам →\to det⁡Adet⁡B\det A\det B.

P07. Формулы Крамера

Утверждение. Если det⁡A≠0\det A\ne0, единственное решение Ax=bAx=b имеет координаты xi=det⁡Ai/det⁡Ax_i=\det A_i/\det A, где AiA_i получена из AA заменой ii-го столбца на bb.

Доказательство. Обозначим столбцы AA через a1,…,ana_1,\ldots,a_n. Из Ax=bAx=b следует b=x1a1+⋯+xnanb=x_1a_1+\cdots+x_na_n. В определителе AiA_i заменим ii-й столбец этой суммой и применим линейность:

det⁡Ai=∑k=1nxkdet⁡(a1,…,ai−1,ak,ai+1,…,an).\det A_i=\sum_{k=1}^{n}x_k\det(a_1,\ldots,a_{i-1},a_k,a_{i+1},\ldots,a_n).

При k≠ik\ne i внутри стоят два одинаковых столбца aka_k, значит слагаемое равно нулю. При k=ik=i получаем det⁡Ai=xidet⁡A\det A_i=x_i\det A. Делим на det⁡A≠0\det A\ne0 — искомая формула. Существование и единственность xx обеспечены обратимостью AA. ▫\square

План: b=∑xkakb=\sum x_ka_k →\to подставить в столбец ii →\to повторяющиеся столбцы убивают остальные слагаемые →\to det⁡Ai=xidet⁡A\det A_i=x_i\det A.

Проверка: что будет неверно, если заменять строку, а не столбец?

P08. Критерий существования обратной матрицы

Утверждение. Квадратная AA обратима тогда и только тогда, когда det⁡A≠0\det A\ne0.

Доказательство необходимости. Если существует A−1A^{-1}, по P06 1=det⁡E=det⁡(AA−1)=det⁡A⋅det⁡A−11=\det E=\det(AA^{-1})=\det A\cdot\det A^{-1}, поэтому det⁡A≠0\det A\ne0.

Доказательство достаточности. Пусть det⁡A≠0\det A\ne0. Возьмём матрицу алгебраических дополнений C=(Cij)C=(C_{ij}) и её транспонирование adj⁡A=CT\operatorname{adj}A=C^T. По формулам истинного и фальшивого разложений (D09–D10)

[Aadj⁡A]ij=∑k=1naikCjk={det⁡A,i=j,0,i≠j.[A\operatorname{adj}A]_{ij}=\sum_{k=1}^{n}a_{ik}C_{jk}=\begin{cases}\det A,&i=j,\\0,&i\ne j.\end{cases}

Аналогично adj⁡AA=(det⁡A)E\operatorname{adj}A\,A=(\det A)E, используя разложения по столбцам. Следовательно,

Aadj⁡Adet⁡A=E=adj⁡Adet⁡AA,A\frac{\operatorname{adj}A}{\det A}=E=\frac{\operatorname{adj}A}{\det A}A,

то есть обратная существует и равна adj⁡A/det⁡A\operatorname{adj}A/\det A. ▫\square

План: обратная ⇒\Rightarrow det⁡(AA−1)=1\det(AA^{-1})=1; обратная сторона ⇒\Rightarrow союзная матрица →\to Aadj⁡A=(det⁡A)EA\operatorname{adj}A=(\det A)E через настоящее и фальшивое разложения →\to разделить на ненулевой определитель.

Проверка: почему нельзя воспользоваться этой формулой при det⁡A=0\det A=0?

P09. Ранг при транспонировании

Утверждение. rank⁡(AT)=rank⁡(A)\operatorname{rank}(A^T)=\operatorname{rank}(A) для любой прямоугольной матрицы AA.

Доказательство. Минор AA, полученный выбором kk строк с индексами i1,…,iki_1,\ldots,i_k и kk столбцов с индексами j1,…,jkj_1,\ldots,j_k, после транспонирования превращается в минор ATA^T на kk строках j1,…,jkj_1,\ldots,j_k и столбцах i1,…,iki_1,\ldots,i_k. Эти две квадратные подматрицы транспонированы, а по P02 их определители равны. Поэтому множества порядков ненулевых миноров у AA и ATA^T совпадают, а максимальные порядки одинаковы. ▫\square

План: миноры AA и ATA^T взаимно однозначно соответствуют друг другу →\to их значения равны по P02 →\to максимальный порядок одинаков.

Проверка: почему не надо предполагать, что AA квадратная?

P10. Теорема о ранге (в студенческом конспекте отсутствует)

Утверждение. Ранг матрицы по ненулевым минорам равен и максимальному числу линейно независимых строк, и максимальному числу линейно независимых столбцов.

Доказательство с использованием известной теоремы о базисном миноре. Если r=0r=0, все элементы матрицы равны нулю, следовательно, все её строки и столбцы нулевые, и оба максимума равны 0. Далее считаем r=rank⁡A>0r=\operatorname{rank}A>0 и выбираем любой базисный минор порядка rr. По теореме о базисном миноре его rr строк линейно независимы, а любая другая строка AA — линейная комбинация этих rr строк. Следовательно, существует rr линейно независимых строк, но r+1r+1 независимых строк быть не может. Раскроем этот шаг: возьмём любые r+1r+1 строк wjw_j и выразим их через базисные строки b1,…,brb_1,\ldots,b_r как wj=∑k=1rckjbkw_j=\sum_{k=1}^r c_{kj}b_k. Однородная система ∑j=1r+1ckjαj=0\sum_{j=1}^{r+1}c_{kj}\alpha_j=0 (k=1,…,rk=1,\ldots,r) имеет rr уравнений и r+1r+1 неизвестную; по методу Гаусса у неё есть ненулевое решение α\alpha. Для этих коэффициентов

∑j=1r+1αjwj=∑k=1r(∑j=1r+1ckjαj)bk=0.\sum_{j=1}^{r+1}\alpha_jw_j=\sum_{k=1}^r\left(\sum_{j=1}^{r+1}c_{kj}\alpha_j\right)b_k=0.

Значит выбранные r+1r+1 строк линейно зависимы, и максимальное число независимых строк равно rr.

Точно так же базисные rr столбцов линейно независимы, а все остальные столбцы выражаются через них. Поэтому максимальное число независимых столбцов тоже равно rr. ▫\square

План: взять базисный минор порядка rr →\to его строки/столбцы независимы →\to все остальные — их комбинации →\to больше rr независимых векторов быть не может →\to оба максимума равны rr.

Проверка: почему недостаточно доказать, что выбранные rr строк независимы? Что ещё запрещает существование r+1r+1 независимых строк?

P11. Критерий невырожденности через базисный минор

Утверждение. Для квадратной матрицы AA порядка nn равносильны: (1) det⁡A≠0\det A\ne0; (2) rank⁡A=n\operatorname{rank}A=n; (3) nn строк линейно независимы; (4) nn столбцов линейно независимы.

Доказательство. У квадратной матрицы n×nn\times n ровно один минор порядка nn — её собственный определитель. Поэтому det⁡A≠0⇔rank⁡A=n\det A\ne0\iff\operatorname{rank}A=n. По теореме о ранге (P10) последнее равносильно тому, что максимальное число линейно независимых строк равно nn; поскольку строк всего nn, все строки независимы. Тот же аргумент применяем к столбцам. ▫\square

Из P08 дополнительно следует равносильность существованию обратной матрицы.

План: единственный nn-минор det⁡A\det A →\to det⁡A≠0⇔r=n\det A\ne0\iff r=n →\to P10 даёт независимость всех строк/столбцов.
